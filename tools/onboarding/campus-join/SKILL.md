# 加入自习室项目

## 执行条件

成员在 IDE 中打开已解压的个人包，或希望恢复上次安装。定位与本技能同包的 start.cmd、start.command 和 member.json。

## 输入

代号由个人包提供。成员在本机终端填写自己的 GitHub 用户名，或确认使用已登录的账号。系统授权和浏览器账号登录由成员本人操作。访问码由启动程序读取。

## 执行过程

1. **Stage 1 准备环境**。用可交互的本机终端执行 Windows 的 start.cmd 或 macOS 的 bash start.command。首次使用的电脑通过系统安装器补齐工具。收到系统重启提示时，重启后再打开同一启动程序。
2. **Stage 2 绑定账号**。让成员在自己的 GitHub 浏览器授权页确认账号。程序核对已登录账号，使用自己的名额登记，然后检查仓库邀请和写权限。等待邀请时可以重新运行。
3. **Stage 3 核对分工**。程序校验冻结提交、本人模块、前后端两个视图、测试镜像和五个开发技能。重试使用同一目录。
4. **Stage 4 进入开发**。在 IDE 打开程序输出的项目目录。先用 campus-workflow 查看本人需求和既有收据，再由成员启动待办任务。

## 输出

本机项目路径、代号、模块、账号和两个层的待办。凭据留在个人电脑。

## 完成条件

终端显示“项目就绪”，已验证 GitHub 写权限和公网缓冲站身份，两个层都能读到本模块需求。
