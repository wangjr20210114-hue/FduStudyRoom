## 场景格式

每个场景按“场景概述”和“操作步骤与预期结果”书写，操作和对应结果合并在编号步骤中。

## 文档维护

spec-network.json是业务规范源。修改后由workflow运行以下生成与检查命令：

```sh
python tools/spec_plan/render.py
python tools/spec_plan/render.py --check
```

编号保留，移出工程条目后出现空号属于正常情况，不代表漏掉业务。
