# 身份、资源与支撑服务后端联调

本轮使用 a、b、f 的缓冲站收件差异，在协调人独立 QA 环境运行两个真实应用、PostgreSQL 18 和 Mailpit。共完成 **82/82 项检查、49 次真实 HTTP 请求**，未修改业务代码。

## 实测结果

| 场景 | 实际结果 |
| --- | --- |
| 登录与请求保护 | 经本次私有 HTTPS 代理登录，使用应用真实安全 Cookie 和 CSRF；未绕过安全配置。 |
| 身份、资格和配置 | 普通账号由注册接口创建，管理员由应用 bootstrap 创建；资格修改使旧会话失效。配置版本更新与历史可查，旧版本更新返回 409；四类权限候选目录可用。 |
| 权限边界 | 普通用户访问管理配置、伪造角色或用户请求头访问审计仍被拒绝；内部资格接口无服务凭据返回 401。 |
| 教室与座位 | 通过公开管理 HTTP 创建教室和座位，读取与带插座筛选正常；普通用户不能写教室，旧版本更新返回 409。 |
| 占用与释放 | 首次占用成功，同键同内容回读原结果；同键异内容与同用户时间重叠返回 409。释放成功后，低版本占用不能复活。 |
| 维修限制与恢复 | 维修限制真实生效后占用被拒绝；恢复保存高版本状态，旧维修消息不能覆盖恢复墓碑。 |
| 通知邮箱验证 | 身份服务经支撑服务把验证邮件交给真实 SMTP/Mailpit；重复请求对本次验证只产生一封邮件。默认链接使用产品 HTTPS 域名和 fragment；其他账号验证被拒绝，本人验证成功。 |
| 审计联通 | 身份域的资格、配置、邮箱事件，以及资源域的教室、座位、占用、释放和维修限制事件，均实际进入支撑服务；使用应用响应返回的 X-Request-Id 可以检索到对应资源事件。 |
| 敏感数据 | 支撑服务的验证回执和普通通知表不含本轮验证令牌或通知邮箱；两应用日志不含本轮验证令牌。报告不保存原始令牌或通知邮箱。 |
| 统计缺失来源 | 个人预约聚合接口尚未实现，统计实际返回 **503 STATISTICS_SOURCE_UNAVAILABLE**，未把缺失来源补成 0。 |
| 身份依赖超时 | 仅暂停本次 QA 的身份所在资源服务，流程服务敏感读取在 **4.469 秒**返回 503；恢复资源服务后读取成功。 |

SMTP 成功仅表示服务器已接收邮件，本次不证明公开邮箱最终送达。教室、账号、资格、参数和资源状态通过公开 HTTP 操作建立；数据库只读查询用于核验，没有直接向业务私有表写入测试状态。
