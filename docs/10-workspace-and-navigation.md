## 页面与范围

登录页删除宣传语、功能介绍、装饰插画、帮助长文及重复提示，保留登录、开发身份标识、认证不可用、加载和错误反馈。沿用已有公共样式；视觉设计后续再做。

| 地址 | 页面 | 访问条件 |
| --- | --- | --- |
| `/` | 跳转工作台 | 由工作台执行身份与权限检查 |
| `/login` | 登录 | 未登录可访问；已有有效身份时进入允许的返回地址 |
| `/workspace` | 空工作台 | 已登录，具有 `identity:read` |
| `/account` | 个人信息 | 已登录，具有 `identity:read` |
| `/system/users` | 账号管理预留页 | 已登录，具有 `identity:users:read` |
| `/forbidden` | 无访问权限 | 已登录 |
| 其他地址 | 页面不存在 | 已登录 |
| `/dev/components` | 原有公共组件预览 | 仅开发构建保留 |

工作台只显示“暂无内容”。账号管理只显示“功能待接入”，尚未实现查询、授权或编辑界面。没有模拟统计、预约、审批或维修数据。

导航只展示具有对应权限的入口。当前身份种子为所有默认角色授予 `identity:read`，仅管理员额外拥有用户管理权限，所以学生和维护人员当前都只显示工作台；三种角色都可通过用户菜单访问个人信息和退出。后续业务模块实现自己的权限后再加入菜单。

## 身份与导航行为

1. 进入受保护页面前请求认证配置和 `/api/auth/me`，确认成功后才挂载页面。
2. 检查过程中清除旧身份；401 / 403 返回登录，网络或服务故障保留错误供重试。
3. 角色用于展示，菜单与路由按后端返回的权限编码判断；地址栏直接输入管理地址也执行检查。
4. 登录后的返回地址仅接受当前明确存在的工作台、个人信息和账号管理路径，再经过权限检查；不接受外部链接或任意路径。
5. 退出成功后清除共享身份并返回登录；退出失败时保留当前已知身份及错误，可以重试。浏览器返回或重新打开工作台时需重新核验。
6. 标签页重新可见或从浏览器页面缓存恢复时再次确认身份，并处理资格失效或权限变化。

身份状态只保存在页面内存；凭据仍由 HttpOnly Cookie 管理，localStorage 只保存语言选择。前端导航控制用于页面体验，真正的数据和操作权限仍由后端接口验证。

## 启动与验证

按 [后端说明](08-login-backend.md) 启动资源服务，然后按 [登录前端说明](09-login-frontend.md) 启动 Vite。打开 http://127.0.0.1:5173/login ，选择明确标记的开发身份登录。正式校方 UIS 仍待 T07，不能用开发账号代替正式认证。

路由采用 HTML5 History；本地 Vite 支持地址刷新。正式部署需为前端页面配置回退到 `index.html`，同时让 `/api`、`/internal` 由相应服务处理，不能将接口错误改成前端页面。正式反向代理配置随后续部署任务实现。

使用 [Vue Router 官方安装说明](https://router.vuejs.org/installation) 及 [导航守卫说明](https://router.vuejs.org/guide/advanced/navigation-guards)；精确版本记录在依赖和锁文件中。
