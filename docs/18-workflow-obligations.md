# workflow管理的工程和过程要求

这些内容从业务spec中移出，在workflow中统一管理。它们不是用户预约、审批或报修时使用的业务功能。

本次只是分类和文档整理，不表示自动化已经实现。已有技能、权限、TDD检查、人工验收、合并和发布规则继续执行；需要真实成员完成或批准的事项不能由AI代签。

## 包含哪些工作

- 成员登记、文件分工、模块隔离和公共变更评审。
- 接口说明的准备、公共组件复用和技术栈保持。
- 环境检查、工具安装、本机运行、数据库升级与初始化。
- 先测后写、回归、故障联调和证据保存。
- 缓冲网站收件、审核、独立检查、72小时同步与合并请求。
- 测试部署、生产批准、发布回退、课程评审和个人报告。
