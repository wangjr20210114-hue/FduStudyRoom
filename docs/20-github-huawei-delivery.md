## 站点与部署产物

- 地址：https://studyroom.seatraces.com；A 记录指向 119.3.126.218。
- 服务器：Ubuntu 22.04，约 7 GB 内存、80 GB 可用磁盘；首次检查 80/443 空闲。
- 应用：Vue 3/TypeScript 静态前端、Java 21 的 resource-service 与 workflow-service、PostgreSQL 18。
- 数据库分为 fdu_study_room 和 fdu_workflow，分别使用自己的账号；共享认证键只放服务器私有配置。
- 发布包包含 web、两个 JAR、版本信息和完整 SHA256 清单；不含源代码凭据、环境文件和数据库备份。
- 服务器固定部署配置与发布包分离，发布包不能改 Compose、宿主挂载或接收脚本。

## 回退边界

应用回退不等于数据库回滚。每次更新前保留私有数据库备份，不自动恢复备份覆盖新业务数据；迁移不兼容或上一版本也无法启动时停止并报告，需要人工决定处理方式。发布目录、数据库卷和其他项目互不清理。

## Git 描述

```text
feat(reservation): 增加预约取消入口

- 在预约详情展示取消按钮
- 取消后释放占用并更新列表
- 补充重复取消和过期预约测试
```

新增功能 feat，修复 fix，重构 refactor；可用 docs/test/build/ci 等类型描述对应基础工作。每次正文必须分点，不能混入密码、访问码或未验证结果。

## 本站发布授权

用户于2026-11-15明确授权：本仓库各分支的 GitHub 推送在 CI 通过后自动更新此华为体验站，无需逐次人工批准。正式生产仍需人工审批。AGENTS.md 已同步这个限定范围，Gitee 的审核和定时交付规则保持原约定。

Actions 环境为 huawei-experience，专用 SSH 用户 fdu-deploy；该密钥只能执行服务器固定的接收程序。服务器 root 密码不进入 GitHub、仓库或 skill。运行镜像首次准备后按本机镜像 ID 固定，每次发布复用，不临时切换镜像标签。

此前自动审批拦截了与旧人工审批规则冲突的无条件上线；此后已取得明确授权。实际部署与 HTTPS 结果以执行记录为准。
